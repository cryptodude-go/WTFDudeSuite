# Rare discoveries audit · 0.27.0

Date: 8 November 2026. Source/live v0.26.0 backed up and verified before changes. Live target is `_forever_`. Installation changes addon files only, never WTF/SavedVariables.

New modules Core/RareScanner.lua (detection/state) and Core/RareAlerts.lua (UI/settings/navigation) load at the end of the TOC. The master switch defaults off. Categories: rare NPC/rare elites, minimap-confirmed treasure containers, optional events and own rare/epic item loot. Public vignette events and visible nameplates/target/mouseover/soft-targets plus one-second bounded polling are used. NPC fallback rarity comes from the existing native NPC database, not copied third-party rare classifications. Controlled pets/players/dead units are rejected. Secret/throwing APIs fail closed; exact world-to-map conversion or native vignette position is needed for navigation.

Dark/gold 430×184 card uses native fonts, faction accent, draggable saved per-character position, scale/opacity/lock, model and sound controls, queue navigation and Dismiss/Ignore/Waypoint. PlayerModel loads the actual unit/cached creature/display; successful NPC displays are learned locally. DressUpModel previews wearable own loot; other items can use SetItem. Unavailable models and treasure objects get a real icon fallback. Async load timeout and stable model key prevent blinking on every scan. Model/window preview does not persistently enable scanning.

Spawn GUID deduplication and bounded per-spawn cooldown preserve separate chests of the same type. Sound rate limit is two seconds, active queue cap 12, history cap 50, seen cache cap 512 and pending uncached item data cap 16/30 seconds. Self-loot formats are taken from localized client strings, not English-only matching. Item data retries are event-driven. Events and own loot alerts default off.

Navigation begins only by explicit Waypoint click, overriding the native route temporarily without advancing the guide. Owned focus and previous focus are tracked. Stop/dismiss/death/vignette removal/expiry/master off retire the detour; old quest focus is restored only if its guide/index are still valid. Repeated Track does not nest rare focus. Moving sightings update the owned focus. Manual quest focus/unfocus and guide switching cancel the detour. Candidate overrides are restored even if native rendering throws. Gathering is deferred while a rare route is selected; corpse/paused behavior stays native. World waypoint ownership/cleanup continues through v0.24.1's existing guards.

Validation: full Lua 5.1 compile/startup and historical 221-guide/13,216-step/90 race-class-faction scenario suite, plus dedicated rare detection/model/state/settings tests and navigation interaction/error-recovery tests. New cases include pets vs rare NPCs, DB rank fallback, secret/error API data, vignette category filters, distinct same-type chests, sound/dedup/cooldown, 3D success/error/timeout, wearable loot and deferred item load, ignored identities, death/despawn/expiry, preview/master/combat switches, bounded queues, movement and navigation cleanup. Tests emulate the game UI/model API; real in-game appearance/detection needs player confirmation. No restricted combat log, protected target/mark commands, chat broadcast or external network request is added to the addon.
