# Suite module audit · 1.0

8 November 2026. Source and live v0.27.0 were backed up and three critical files verified against the prior release ZIP before editing. Rebranding changes display strings and TOC metadata while keeping the internal addon name and saved-variable paths stable.

Native Config owns the new 880×600 dialog geometry: 184 units for the right navigation rail, separate 16-unit content scrollbar gutter, 680-unit content canvas, 34-unit buttons at 38-unit intervals. Thirteen visible tabs fit above the footer. Original tab indexes remain stable. Route and keybinding descriptors are preserved as subpages; controller navigation follows the visible rail. Existing dropdown focus/lifetime handling is unchanged.

Core/Suite.lua registers the module masters, persistent suite flags, dedicated module builders and new commands. Native master values remain the sole source of truth for spam, rares, marking and travel; other modules have independent saved flags. Overall suspension never overwrites these choices. Construction retains the existing builders/widgets, moves mixed controls out of unrelated tabs and reuses legacy subpages without exposing duplicate masters. Settings is not disabled by the suite switch.

Runtime gates cover guide advancement/refresh/arrival, selected guide visibility, crafting/reputation tasks, native and auxiliary arrow paths, owned world/minimap quest pins, route lines, live gathering, gathering circles, soft-target sparkle activation and quest-loot CVars, merchant actions/quest automation/gear suggestions and auto-equip, group marking context plus secure-control configuration, spam event filtering/native-ignore queue, rare detection/rendering/navigation and travel display. Chat announcements and optional activity events have their own gate. Gathering guides remain independent of the crafting switch. Live gathering shutdown clears only transient state; it does not add a skip/ignore or erase saved nodes. Explicit timer previews remain available without persistently enabling travel.

Validation: work/test_suite100.py checks actual module master callbacks and native rows, rail coordinates/content widths/controller traversal, legacy subpages, retained character progress, module isolation, queued-action gates, base/auxiliary arrow hiding, chat mute, gathering cleanup, sparkle settings/CVar master behavior, global suspension/restore and branding metadata. It compiles every Lua source. work/test_rares0270.py passes the complete historical regression chain, including 221 guides, 13,216 steps and 90 race-class-faction combinations. Historical assertions were updated only for relocated community controls, renamed branding, hidden legacy subpages and NPC-specific controls that require a selected target.

The game UI and API are simulated in these tests. Actual client rendering, dragging and combat transitions still require in-game validation. Existing client restrictions and sparkle restart caveats remain. No new network, reporting, protected automatic combat marking or external dependency is introduced.
