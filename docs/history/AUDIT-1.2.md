# Lockpicking audit · 1.2

14 November 2026. Source baseline checked against the v1.1 release ZIP, rollback archive retained, and changed live files verified/backed up. Internal addon/save names remain unchanged. Core/Lockpicking.lua is the only new runtime module, loaded last so it can register the book and wrap profession/task/settings APIs without changing herb/mining storage or detector logic.

Book: skill line 633, localization spell 1809, Pick Lock 1804. Seven factual training bands use existing native object spawn records, filtered by minimum skill and conservative high-tier thresholds. Current suitable zone is preferred; manual zone never silently falls back elsewhere. Rogue/non-learned/live-cap/300-complete states are separate. Skill events invalidate cached live skill data. No fabricated exact chest spawns or live respawn schedule is introduced. Explicit waypoint selection overrides automatic routing as before; Next/Previous clear that focus and skip/restore the checked location.

History: a matching Pick Lock cast must have a captured world GameObject identity/name and matching cast token; otherwise world loot-source GUID plus a known footlocker/chest identity is required. Bag/trade item GUIDs, creature GUIDs, failed/interrupted/stale casts and unrelated world soft targets are rejected. Exact public object coordinates are preferred; otherwise the character's nearby position is labelled approximate. Empty practice boxes have the confirmed cast path. Unknown object evidence is not fabricated; the UI includes a manual approximate marker. Storage is per character, deduplicated within 20 yards, with timestamps/hit count, up to 500 nodes per map and 100 stored maps. Recently opened records remain skipped for ten minutes across reload; transient checked/skip state expires after three minutes. Unknown skill requirements are excluded from automatic training routes.

Rendering uses the same PortraitRing circle artwork, native tooltips and map/minimap projections as gathering. Per-map merged lists and native seed points are cached; world map updates are throttled and minimap projection is current each frame with bounded visible pins. Coordinates are never overwritten by rendering. Recording, known spawns, circles and each map surface have separate toggles. Professions and overall Suite masters apply. The old floating overlay remains removed. Nearby positions are not claimed to be exact or currently spawned.

Validation: work/test_suite120.py verifies actual book selection, live skill/cap, seven tiers, faction/current/manual zones, existing native spawns, Next/Previous, persistent/deduplicated history, exact/nearby positions, success/failure/mismatch handling, world-vs-item/creature loot evidence, bag-cast/unrelated soft target rejection, marker projection, clicked-waypoint cleanup and module/checkbox behavior. All Lua sources compile under Lua 5.1. Historical quest/marking/spam/rare suites, 13-module tests and the v1.1 gear/travel/skin suite pass. The shared startup suite still covers 221 guides, 13,216 steps and 90 race/class/faction scenarios.

Tests use simulated UI/API events, not a full in-game playthrough. The live client’s Lockpicking requirements override old guide tiers. No protected automatic lock opening, enemy targeting, chat broadcasts or new external dependency is added. Installation updates addon files only; never WTF/SavedVariables.
