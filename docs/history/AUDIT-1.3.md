# Gathering skill tooltip audit · 1.3

Reviewed the user-provided ProfessionExtension 1.8.6 ZIP, including gathering, skill, node, tracking, highlight, harvest and settings implementations, and the published project description at https://www.curseforge.com/wow/addons/professionextension (15 November 2026). The uploaded release includes additional AH/session/sharing/marker systems; this release implements the requested herb/mining/skinning skill display, independently inside Suite. Those unrelated systems are not imported. No external addon code or assets are bundled.

Core/GatheringSkills.lua uses Suite's existing profession reader and localized object names/aliases, plus Classic quest-only ore requirements and Wintersbite. Skinning thresholds follow corpse level: 1 through level 10, (level-10)*10 through 20, level*5 thereafter. Difficulty bands relative to minimum skill are 0–24 orange, 25–49 yellow, 50–99 green, 100+ gray; below minimum/unlearned is red. These are estimates, not server skill-up guarantees.

Modern tooltip postcalls register independently for Object, Unit and MinimapMouseover with legacy script/SetText fallbacks. Readable tooltip data and visible lines are merged. Lines are deduplicated against tooltip contents, not a sticky flag, so rebuilt minimap tooltips receive the line again. A recursion guard handles Show callbacks. Skinning needs a readable unit token, dead state, level and localized Skinnable label. Secret text is rejected before parsing. No cursor movement, protected actions, tracking CVar changes, AH scans, chat, network communication or changes to node detector/sound logic.

Settings use native checkmarks and an existing Gathering subpage; all three types default on, with an independent feature master. Gathering and overall Suite masters apply. Existing SavedVariables store the new per-character preferences. No live WTF files are edited.

Validation: targeted simulated Lua 5.1 tests for thresholds, missing profession, multiline/overlapping minimap nodes, duplicate/rebuilt tooltips, corpse eligibility, individual/module/global toggles, secret values and modern hook registration. Existing native startup, guide coverage, 13-module settings, gear/travel/skin, Lockpicking and historical regression suites also run. Automated tests do not replace in-game verification of tooltip layout or client-protected data behavior.
