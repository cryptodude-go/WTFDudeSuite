ForeverFlightTimer (Forever, Interface 16001, internal version 0.1.8) uses a compact movable/scalable timer, classic and modern taxi hover hooks, a validated source/connection/destination snapshot, realm/faction/locale context keys, selected-flight capture, learned durations, unknown elapsed time, stable-landing confirmation and early-landing invalidation. Its listed license is All Rights Reserved. Our integration is independently written around our existing native Travel/TravelClock/TravelDisplay and native skin, preserving boat/zeppelin functionality.

Easy Gear Upgrade 2.3.0 is a Retail addon (12.0.x), MIT-listed, with item-level-first comparisons, weighted secondaries for ties, class/armor/weapon filters, paired-slot/unique-item handling, tooltip lines and standard/third-party window overlays. Retail binding/transmog/secondary assumptions are not transplanted into Forever. Our code uses our existing Classic/Forever class restrictions and weighted-stat reward engine, six configurable profiles, scored native hints/tooltips and standard-window arrows. No Retail-only Warband/transmog system or broad Bagnon/Plumber compatibility is claimed.
